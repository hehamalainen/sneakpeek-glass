# Changelog

## 0.1.0 · 2026-11-18

Helsinki prototype with a local permission relay, a foreground display client, one-time device pairing and single-request decisions. Includes the event concept view and automated relay, hook and browser checks.

Host adapters cover Claude Code, Codex, Antigravity, and GitHub Copilot CLI. The display identifies the requesting host and uses its native decision semantics.
